# 轻量 AI 预筛选（已停用）

该方案曾用于标题级快速过滤。2026-08-27 起，活动内容 Pipeline 已移除 `AiFilterStep`，普通内容只执行一次实体提取与分类调用。本文件仅保留历史设计背景，不再对应可执行代码或回放脚本。

## 目标

过滤阶段只负责快速排除广告、灌水、纯情绪和无信息量内容，不执行深度事实核验。完整正文只在内容通过后发送给实体提取任务。

当前生产流程不再使用该过滤阶段。

## 输入策略

- RSS、V2EX 等有标题内容：只发送标题、数据源名称和链接域名。
- Twitter 等无标题内容：发送规范化后的前 300 个字符。
- 标题最长保留 200 个字符。
- 不因缺少正文而拒绝信息明确的标题。

## 决策规则

- `pass`：价值分 50～100。
- `quarantine`：价值分 30～49，或真实性不确定、安全待审。
- `reject`：价值分 0～29。
- 明确色情、骚扰或诈骗风险始终进入隔离区。
- 模型决策和评分不一致时，代码按照同一分段规则降级到隔离或拒绝。

评分只用于轻量分流和后续观测，不代表事实真实性或内容质量的精确测量。

## 调用约束

- Prompt 版本：`v2.0`。
- 单次过滤最大输出：400 Token。
- 不增加额外模型调用。
- 当时的 Provider 与模型由任务环境变量控制；相关过滤任务配置现已移除。

## 验证重点

- 有标题时 Prompt 不得包含正文。
- 无标题时内容片段不得超过 300 个字符。
- 套餐、价格、性能、版本、风险和具体问题类标题应优先保留。
- 广告、纯情绪和无明确对象内容应继续拒绝。
